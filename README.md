# nasa-field-shift
A project submitted to the 2026 NASA Space Apps challenge for the theme: Field Shift: Adapting Farms with NASA Data

# Running the backend

**Locally:**

1. Run `cd ./backend`
1. Run `pip install "fastapi[standard]"` or `pip install fastapi`
2. Run `fastapi dev main.py` or `uv fastapi run dev`
